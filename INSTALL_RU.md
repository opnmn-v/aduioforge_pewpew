# Ambient Forge — установка и использование

Эта версия поддерживается **opnmn-v** и основана на [Ambient Forge от Marevo](https://github.com/marevoteam-wq/ambient-forge). Авторство исходной версии и [MIT-лицензия](LICENSE) сохранены. Изменения этого форка публикуются отдельно от проекта Marevo.

## Установка в Owlbear Rodeo

1. Если переходите с другой версии, нажмите **Export** и сохраните библиотеку `.aforge`.
2. В настройках расширений Owlbear Rodeo добавьте custom extension по адресу:

   ```text
   https://opnmn-v.github.io/aduioforge_pewpew/manifest.json
   ```

3. Включите расширение в комнате. Отключите другую версию Ambient Forge в этой же комнате: версии используют общие каналы синхронизации.
4. Откройте панель, при необходимости импортируйте `.aforge` и нажмите **Enable audio**. Каждый слушатель должен разрешить воспроизведение в своём браузере.

Библиотека хранится в браузере. Перед очисткой данных или сменой адреса сайта делайте Export. Файл `.aforge` содержит ссылки и настройки, а не сами аудиофайлы.

## Плейлисты и управление

Сцена работает как плейлист: одновременно играет одна дорожка этой сцены. Несколько разных сцен можно запустить вместе.

- **Play** начинает случайный круг; повторное нажатие останавливает сцену.
- **Следующий трек** выбирает случайную дорожку из оставшихся в текущем круге. Когда список исчерпан, начинается новый круг.
- **Shuffle** сбрасывает очередь и начинает новый случайный круг из всего плейлиста.
- **Pause** приостанавливает сцену или все сцены, сохраняя позицию.
- **Everyone / Only me** задаёт область воспроизведения. Общая громкость относится к вашему браузеру; громкость сцены синхронизируется с её состоянием.

Автопереход выполняет фоновый плеер: панель расширения можно закрывать, но вкладку комнаты ведущего нужно оставить открытой. Воспроизведение зависит от доступа к источнику и разрешений браузера. При блокировке нажмите Enable audio; при Source error проверьте ссылку.

## Редактирование треков

Вставьте ссылку в пустую строку внизу списка — следующая пустая строка появится автоматически. Неиспользованные пустые строки не сохраняются. После изменений нажмите **Save scene**.

Тип источника определяется по ссылке. Название подставляется из имени аудиофайла или названия видео YouTube, если доступен запрос метаданных. Его можно изменить вручную.

Кнопка **▶ возле названия дорожки** позволяет прослушать её локально. Повторное нажатие останавливает прослушивание; выбор другой дорожки заменяет предыдущую. Закрытие или сохранение редактора также останавливает прослушивание.

Поля **Start / End** задают позиции в исходном файле или видео:

- `1600` — 1600 секунд;
- `7:03` — 7 минут 3 секунды;
- `1:07:03` — 1 час 7 минут 3 секунды.

Пишите без слова «сек»; минуты и секунды после двоеточия — двумя цифрами от `00` до `59`. Пустой Start означает начало источника, пустой End — его естественное завершение. End должен быть позже Start. Например, Start `1:00` и End `7:03` означают фрагмент с первой минуты до позиции 7:03, а не длительность 7:03.

В режиме плейлиста отдельная дорожка не зацикливается. После её окончания или заданного End запускается следующая. Старые настройки Loop, Seamless loop, Delay и Mute не представлены в текущем редакторе.

## Ссылки на аудио

Подходят публичные прямые ссылки на MP3, OGG, WAV и другие поддерживаемые браузером аудиоформаты, Dropbox и отдельные видео YouTube. Файлы с компьютера приложение на сервер не загружает.

Для Dropbox включите доступ по ссылке без входа в аккаунт и вставьте share URL. Приложение подготовит ссылку для воспроизведения, сохранив `rlkey`. Обычная страница просмотра Google Drive не является прямой аудиоссылкой.

YouTube использует видеоплеер, а не отдельный аудиопоток. Каждый слушатель загружает источник самостоятельно. Вставляйте ссылку на конкретное видео: автоматического импорта всего YouTube-плейлиста нет.

## Публикация GitHub Pages

В репозитории [opnmn-v/aduioforge_pewpew](https://github.com/opnmn-v/aduioforge_pewpew) выберите **Settings → Pages → Source → GitHub Actions**. Отправка коммита в `main` запускает workflow **Deploy GitHub Pages**; его также можно запустить вручную во вкладке Actions.

Workflow устанавливает зависимости через `npm ci`, запускает тесты и сборку, затем публикует корневой `manifest.json` и готовую папку `dist/`. Манифест указывает на `/aduioforge_pewpew/dist/`. Успешный push ещё не означает успешную публикацию: проверьте этап deploy в Actions.

При изменении домена или пути нужно согласованно обновить `base` в `vite.config.ts`, пути в `public/manifest.json` и корневом `manifest.json`, а также схему публикации. После изменения адресов расширения может понадобиться повторное добавление в Owlbear.

Если сайт не открывается с VPN, проверьте прямую ссылку на сайт в браузере. Настройки расширения не устраняют недоступность хостинга из вашей сети.

## Разработка и проверки

Требуется Node.js **22.12 или новее**. Из корня репозитория:

```bash
npm ci
npm run check
npm run dev
```

Режим визуального предпросмотра: `http://localhost:5173/aduioforge_pewpew/dist/?preview=1`. Он показывает интерфейс без подключения к комнате. `npm run build` создаёт готовый сайт в `dist/`; корневые HTML-файлы служат входами сборки.

Браузерные проверки требуют Playwright и Chromium. Playwright можно установить отдельно от проекта:

```bash
npm install --prefix /tmp/ambient-forge-browser playwright
/tmp/ambient-forge-browser/node_modules/.bin/playwright install chromium
CODEX_PRIMARY_RUNTIME_NODE_MODULES=/tmp/ambient-forge-browser/node_modules npm run test:browser
```

Для уже установленного Chromium задайте `CHROMIUM_PATH`. Тестовый сценарий использует настоящий HTMLAudioElement с синтетическим WAV и имитацию Owlbear SDK; тесты YouTube используют имитацию API. Это не заменяет проверку реального YouTube внутри комнаты. Снимки интерфейса по умолчанию сохраняются в `/tmp/ambient-forge-browser-tests`; путь меняется через `BROWSER_TEST_ARTIFACT_DIR`.
