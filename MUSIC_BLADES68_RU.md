# Музыка для Blades ’68: сначала функции сцен, затем источники

Это список произведений для самостоятельного прослушивания, а не готовый плейлист. Подбор под криминальный, шпионский Досквол с ретро-звучанием 1960–70-х; современные стилизации отмечены отдельно. Связь саундтреков со сценами — моя рекомендация, а не характеристика из правил. Полный PDF правил в этой сессии не прочитан: ориентир — доступное описание кампании и прошлый запрос на фон, напряжение, погоню, бой, отдых и диско.

## 1. Какие музыкальные состояния нужны

| Папка | Что происходит | Чего ждать от музыки |
|---|---|---|
| Город / обычный фон | Разговоры, торговля, перемещения, домашняя база | Сдержанный грув, минимум солирующего вокала и драматических кульминаций |
| Дело / подготовка | Разведка, переговоры с заказчиком, план, сбор информации | Любопытство и ощущение профессиональной работы; не объявлять опасность заранее |
| Проникновение / слежка | Незаметная работа под риском обнаружения | Пульс и ожидание, больше пространства для речи |
| Давление / разоблачение | Допрос, подозрение, трудная сделка, приближение патруля | Медленная угроза. Отличать от активного боя |
| Погоня / побег | Автоподы Red Torque, преследование по крышам, уход из доков | Движение и настойчивый ритм |
| Драка / перестрелка | Уже начавшаяся открытая схватка | Более жёсткий удар и плотная фактура |
| Паранормальное / аномалия | Эхо, странный товар Dealers, нарушения привычной реальности | Психоделия и необычные тембры; отдельный более страшный вариант для действительно опасной сцены |
| Передышка / последствия | Разгрузка, личные сцены, лечение, возвращение на базу | Спокойствие, усталость или горькое послевкусие |
| Клуб / запой | Бар, тусовка, дискотека, музыка внутри мира | Фанк, соул, диско; вокал допустим, пока он не мешает разговору |

Не нужен отдельный плейлист для каждого механического шага. Выплата, heat и aftermath обычно остаются на фоне «Город» или «Последствия». Для твоей кампании важнее разделить скрытое напряжение, открытую опасность и паранормальное.

## 2. Что послушать в первую очередь

| Произведение | Автор музыки | На какие папки прослушивать | Почему я предлагаю его |
|---|---|---|---|
| **Deathloop (2021, игра)** | Tom Salta; также Erich Talaba и Ross Tregenza на альбоме | Город, проникновение, бой, аномалия | Первый кандидат на общий звуковой язык: ретрофутуризм, шпионская подача, электрические инструменты и несколько уровней интенсивности. Современная стилизация |
| **The Man from U.N.C.L.E. / «Агенты А.Н.К.Л.» (2015, фильм)** | Daniel Pemberton | Подготовка, проникновение, погоня | Стильные профессиональные преступники и шпионы, изобретательная перкуссия и ретро-тембры. Современная стилизация |
| **Get Carter / «Убрать Картера» (1971, фильм)** | Roy Budd | Город, сделки, криминал, последствия | Более приземлённый и холодный город. Особенно близко к докам, поставщикам и разговорам с синдикатами |
| **The Ipcress File / «Досье Ипкресс» (1965, фильм)** | John Barry | Разведка, слежка, допрос, паранойя | Для истории, где за тобой наблюдают и все чего-то недоговаривают. Менее героическое ощущение, чем у привычного Бонда |
| **Bullitt / «Буллит» (1968, фильм)** | Lalo Schifrin | Город, расследование, движение, действие | Джазовый криминальный саунд эпохи. Выбирать по реальной интенсивности трека, а не по воспоминанию о погоне из фильма |
| **Lupin III Part II (с 1977, анимация)** | Yuji Ohno | Подготовка, авантюра, погоня, удачное дело | Подвижное криминальное приключение. Для более серьёзной игры выбирать менее комические и менее фанфарные фрагменты |
| **Lupin the Third “Jazz” (1999, альбом по анимации)** | Yuji Ohno Trio | Бар, город, личные сцены, передышка | Инструментальные джазовые версии; удобнее для долгого разговора. Это поздние аранжировки, а не записи 1968 года |
| **The Conversation / «Разговор» (1974, фильм)** | David Shire | Паранойя, личные сцены, тяжёлые последствия | Одиночество, сомнения, прослушка; полезен для эмоционального снижения после дела |
| **Assault on Precinct 13 / «Нападение на 13-й участок» (1976, фильм)** | John Carpenter | Давление, осада, опасная перестрелка | Холодная повторяемая электронная угроза; контраст к обычному джазу. В сети много поздних перезаписей — проверяй версию |
| **La Planète sauvage / «Дикая планета» (1973, анимация)** | Alain Goraguer | Аномалии, странные районы, Echo-weed | Психоделическая чуждость без обязательного перехода в хоррор; особенно интересный кандидат для Dealers |
| **Suspiria / «Суспирия» (1977, фильм)** | Goblin | Оккультная опасность, кульминация аномалии | Уже явный ужас и ритуальность; не ставить на каждое упоминание сверхъестественного. Искать версию Goblin 1977, а не музыку ремейка 2018 |
| **Midnight Express / «Полуночный экспресс» (1978, фильм)** | Giorgio Moroder | Погоня, побег, клуб | Раннее электронное диско и моторный ритм. Это более поздний край диапазона 1960–70-х, а не строгая реконструкция 1968 |

Первые пять источников для быстрого отбора: **Deathloop → Get Carter → The Man from U.N.C.L.E. → La Planète sauvage → Lupin the Third “Jazz”**. Они дадут разные стороны одного мира: ретрофутуризм, грязный криминал, профессиональную авантюру, психоделию и отдых.

## 3. Как отбирать и раскладывать

1. Прослушивать альбом по функциям из первой таблицы. Сначала выбрать по 2–3 подходящих трека на функцию.
2. Отделять score от песен и диалоговых вставок. Например, издание Get Carter содержит и короткие записи реплик.
3. Для обычного фона выбирать инструментальную музыку с устойчивой энергией. Короткую кульминационную тему оставить для смены сцены.
4. В расширении сделать папки по функциям, а внутри — сцены с одним музыкальным треком. Кнопка Random scene заменит музыку в этой папке, сохранив дождь или шум города из другой папки.
5. Если одна сцена содержит несколько альтернативных песен, использовать Random track. Обычный Play по-прежнему запускает все дорожки сцены вместе. YouTube-плейлист по ссылке `list=...` не импортируется автоматически.
6. Короткую атмосферу хранить отдельной сценой. Seamless loop подходит только подготовленным коротким файлам по прямой ссылке; для YouTube бесшовный повтор не обещается.
